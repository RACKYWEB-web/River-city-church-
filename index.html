Module 1 — Variables, Types & Scope
JavaScript Mastery · Lesson 1 of 42 · 18 min read
📌 Key Takeaways
After this module, you will understand how JavaScript stores and manages data, the difference between mutable and immutable variables, and why scope is critical to writing bug-free code.

1.1 — What is a Variable?

A variable is a named container that stores a value in memory. Think of it as a labelled box — you name the box, put something inside, and retrieve it later using that name.

In JavaScript, there are three ways to declare variables:

JavaScript · Variables
// 1. var — function-scoped, avoid in modern JS
var name = "Alice";

// 2. let — block-scoped, value can change
let age = 25;
age = 26; // ✅ Allowed

// 3. const — block-scoped, value cannot be reassigned
const PI = 3.14159;
PI = 3; // ❌ TypeError: Assignment to constant variable
💡 Best Practice: Always use const by default. Only use let when you know the value will change. Avoid var entirely in modern JavaScript.

1.2 — Data Types

JavaScript has 8 primitive data types. Understanding each is essential to avoiding bugs:

String
Text values: "Hello" or 'World'
Number
Integers & floats: 42, 3.14
Boolean
True/false: true or false
Undefined
Variable declared but not assigned
Null
Intentional absence of value
Object
Key-value pairs: {}

1.3 — Scope Explained

Scope determines where in your code a variable is accessible. JavaScript has three types of scope:

JavaScript · Scope
// Global Scope — accessible everywhere
const globalVar = "I am global";

function myFunction() {
  // Function Scope — only inside this function
  const funcVar = "I am local";

  if (true) {
    // Block Scope — only inside this if-block
    let blockVar = "I am block-scoped";
    console.log(blockVar); // ✅ Works
  }
  console.log(blockVar); // ❌ ReferenceError
}

Module 2 — Functions & Scope
JavaScript Mastery · Lesson 2 of 42 · 22 min read
📌 Key Takeaways
You'll learn how to declare functions using three different syntaxes, understand the difference between parameters and arguments, and master the concept of hoisting.

2.1 — Declaring Functions

Functions are reusable blocks of code. JavaScript offers three ways to write them, each with subtle differences you must understand:

// 1. Function Declaration (hoisted)
function greet(name) {
  return `Hello, ${name}!`;
}

// 2. Function Expression (not hoisted)
const greet = function(name) {
  return `Hello, ${name}!`;
};

// 3. Arrow Function (concise, no own 'this')
const greet = (name) => `Hello, ${name}!`;

Module 3 — Arrays & Objects
Arrays store ordered lists of values. Objects store unordered collections of key-value pairs. Together, they form the backbone of all data management in JavaScript.
// Array — ordered list
const skills = ['HTML', 'CSS', 'JavaScript'];
console.log(skills[0]); // 'HTML'

// Object — key-value pairs
const user = {
  name: 'Alex',
  age: 28,
  isStudent: true
};
console.log(user.name); // 'Alex'

Module 1 — What is Artificial Intelligence?
AI is the simulation of human intelligence by computer systems. It includes learning, reasoning, and self-correction. The field encompasses machine learning, deep learning, natural language processing, and computer vision.

Types of AI

🤖
Narrow AI
Designed for a specific task — e.g., chess, image recognition
🧠
General AI
Human-level intelligence across any cognitive task — theoretical
